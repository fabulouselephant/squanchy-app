## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

To run unit test using

```bash
 pnpm vitest
```
To run e2e test

```bash
pnpm cypress open
```
